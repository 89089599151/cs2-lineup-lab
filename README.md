# Lineup Lab

Поиск смоков Mirage для локальной тренировки в Counter-Strike 2.

- **По старту** — поставь точку на радаре. Сайт показывает, куда долетают смоки с ближайшей рассчитанной позиции. В панели указаны точный старт и расстояние до него.
- **По цели** — поставь точку в нужном месте. Сайт показывает позиции, с которых точка остановки гранаты попадает в выбранный радиус. Если рядом есть результаты на разных высотах, можно выбрать диапазон Z.
- **Сторона** — выбери атаку T, защиту CT или обе стороны. Рассчитанные позиции отнесены к стороне по длине маршрута от её спаунов. В ручном каталоге сторона определяется по близости к спауну.
- **Каталог** — 11 раскидок дыма, флешки, молотова и HE со ссылками на источники.

Клик по результату открывает карточку с техникой броска, кнопками мыши, временем полёта и командой. Включи консоль разработчика, открой локальную тренировку на Mirage и вставь скопированную строку. Она выставит позицию и прицел и выдаст гранату. Бросок выполняется вручную.

## Данные расчёта

Радар построен по локальной навигационной сетке и геометрии столкновений Mirage. Для поиска использована установленная сборка CS2 `26798866` (клиент `2000948`). Атлас содержит 143 779 рассчитанных вариантов из 436 стартовых позиций. Основная сетка стартов имеет шаг 144 игровых единицы. Шаг перебора yaw — 15°, pitch — 10°. Поддерживаются броски с места и в прыжке с ЛКМ, ПКМ или обеими кнопками. Похожие броски группируются, а в карточке показан один вариант группы.

Положение дыма определяется по точке остановки гранаты. Допуск измеряется на плане карты. Для результата можно открыть рассчитанную траекторию с отскоками. Покрытие дымом обзорных линий и шаговые броски требуют отдельного моделирования. Пять контрольных смоков Valve с известными точками остановки уложились в допуск гайда 80 игровых единиц. Отдельные новые броски проверяй в локальной тренировке. [Описание Map Guides от Valve](https://www.counter-strike.net/newsentry/532126482488623353)

Атлас рассчитан отдельно от сайта инструментом [CS2 Smoke Solver](https://github.com/NC1107/cs2-smoke-solver/tree/7ebba5b) (PolyForm Noncommercial 1.0.0). Сайт загружает сжатый индекс, а точки полёта — отдельно по мере выбора броска. Код симулятора и файлы игры не входят в этот репозиторий.
