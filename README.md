# Lineup Lab

Проверенные смоки Mirage для локальной тренировки в CS2.

- **По старту** ищет проверенные места броска в пределах 128 игровых единиц от выбранной точки.
- **По цели** ищет реальные точки раскрытия в заданном радиусе. Можно выбрать сторону, технику и высоту.
- **Каталог** по умолчанию показывает проверенные в CS2 смоки. Другие типы гранат доступны отдельным фильтром.

В карточке можно скопировать команду для локальной тренировки. Она установит игрока в исходную позицию, выставит прицел и выдаст гранату. Бросок выполняется вручную.

## Проверка данных

Точку раскрытия сохраняет сама игра через аннотацию после фактического броска на локальной Mirage. Для опубликованных смоков [записаны дата, сборка и результаты проверок](./data/mirage-live-checks.js). Радар показывает старт, измеренную точку раскрытия и соединяющий их пунктир.

Исходные рецепты и результаты симуляции сохранены для дальнейших проверок. В поиске и каталоге смоков показываются только подтверждённые в игре записи. [История и источники каталога](./CATALOG.md)

## Локальный запуск

```powershell
cd "$env:USERPROFILE\Desktop\CS2"
py -m http.server 8765 --bind 127.0.0.1
```

[Открыть локальную страницу](http://127.0.0.1:8765/). Тесты запускаются командой `node --test`.

Радар масштабируется колёсиком, жестом или кнопками. Через «Карта» можно открыть локальный геопривязанный обзор Mirage 1024 × 1024.

## Геометрия Mirage и надёжность симуляций

Приложены исходные физические ресурсы карты из Valve VPK, декодированная навигационная сетка Mirage и проверки 143 779 расчётных траекторий. Расчётный поиск исключает броски с неподходящим/неизвестным уровнем конечной точки, но **это не проверка полной траектории**. Публичный каталог по-прежнему показывает только подтверждённые в CS2 смоки. Подробности, команды для пересчёта и границы точности — в [GEOMETRY.md](./GEOMETRY.md).
