# Lineup Lab

Поиск смоков Mirage для локальной тренировки в CS2.

- **По старту** ищет варианты с выбранной позиции и с близких игровых позиций в пределах 128 единиц.
- **По цели** ищет позиции броска по высоте и радиусу раскрытия. В обоих режимах можно выбрать сторону, технику и уровень карты.
- **Каталог** по умолчанию показывает проверенные в CS2 смоки. Другие типы гранат доступны отдельным фильтром.

В карточке можно скопировать команду для локальной тренировки. Она установит игрока в исходную позицию, выставит прицел и выдаст гранату. Бросок выполняется вручную.

## Проверка данных

Точку раскрытия сохраняет сама игра через аннотацию после фактического броска на локальной Mirage. Выдача сверяет высоту раскрытия с проходимыми уровнями из оригинального `de_mirage.vpk` сборки Steam `26798866`. Если одна точка на радаре соответствует двум уровням карты, поиск предлагает выбрать высоту. Для опубликованных смоков [записаны дата, сборка и результаты проверок](./data/mirage-live-checks.js). Радар показывает старт, измеренную точку раскрытия и соединяющий их пунктир.

Таблицу уровней создаёт [генератор из локального VPK](./tools/generate-mirage-heights.py). Поставить точку можно в пределах проходимых участков Mirage. В режимах поиска рядом с проверенными бросками отображаются отдельно помеченные варианты, рассчитанные по коллизиям карты. Фильтр высоты исключает попадания на другой уровень. [История и источники каталога](./CATALOG.md)

Расчётные варианты проверяются по траектории полёта, месту остановки гранаты и чувствительности к небольшому отклонению прицела. Для пересчёта нужны .NET 10, локальная установка CS2 и исходный код [CS2 Smoke Solver](https://github.com/NC1107/cs2-smoke-solver/tree/7ebba5b). Команды ниже выполняются из корня проекта. Укажи пути к игре и к исходникам решателя в `$game` и `$solver`, а извлечение сделай в отдельную папку `$extracted`.

```powershell
dotnet run --project "$solver/src/Cli" -c Release -- extract --game $game --map de_mirage --out $extracted
dotnet run --project tools/mirage-calculation -c Release "-p:SmokeSolverRoot=$solver" -- $game $extracted assets/mirage-smokes.json.gz assets/mirage-calculated.json
```

## Локальный запуск

```powershell
cd "$env:USERPROFILE\Desktop\CS2"
py -m http.server 8765 --bind 127.0.0.1
```

[Открыть локальную страницу](http://127.0.0.1:8765/). Тесты запускаются командой `node --test`.

Радар масштабируется колёсиком, жестом или кнопками. Через «Карта» можно открыть локальный геопривязанный обзор Mirage 1024 × 1024.
