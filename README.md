# Lineup Lab

Проверенные смоки Mirage для локальной тренировки в CS2.

- **По старту** ищет проверенные места броска в пределах 128 игровых единиц от выбранной точки.
- **По цели** ищет реальные точки раскрытия в заданном радиусе. Можно выбрать сторону, технику и высоту.
- **Каталог** по умолчанию показывает проверенные в CS2 смоки. Другие типы гранат доступны отдельным фильтром.

В карточке можно скопировать команду для локальной тренировки. Она установит игрока в исходную позицию, выставит прицел и выдаст гранату. Бросок выполняется вручную.

## Проверка данных

Точку раскрытия сохраняет сама игра через аннотацию после фактического броска на локальной Mirage. Выдача сверяет высоту раскрытия с проходимыми уровнями из оригинального `de_mirage.vpk` сборки Steam `26798866`. Если одна точка на радаре соответствует двум уровням карты, поиск предлагает выбрать высоту. Для опубликованных смоков [записаны дата, сборка и результаты проверок](./data/mirage-live-checks.js). Радар показывает старт, измеренную точку раскрытия и соединяющий их пунктир.

Таблицу уровней создаёт [генератор из локального VPK](./tools/generate-mirage-heights.py). Исходные рецепты и результаты симуляции сохранены для дальнейших проверок. В поиске и каталоге смоков показываются только подтверждённые в игре записи. [История и источники каталога](./CATALOG.md)

## Локальный запуск

```powershell
cd "$env:USERPROFILE\Desktop\CS2"
py -m http.server 8765 --bind 127.0.0.1
```

[Открыть локальную страницу](http://127.0.0.1:8765/). Тесты запускаются командой `node --test`.

Радар масштабируется колёсиком, жестом или кнопками. Через «Карта» можно открыть локальный геопривязанный обзор Mirage 1024 × 1024.
