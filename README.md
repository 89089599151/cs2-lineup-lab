# Lineup Lab

Каталог раскидок для тренировки в CS2. В первой версии есть Mirage и 11 раскидок для дыма, флешки, молотова и HE.

## Как повторить бросок

1. Включи консоль разработчика в CS2 и запусти локальную тренировку на Mirage. Из главного меню можно ввести `map de_mirage`.
2. На сайте выбери раскид и нажми «Скопировать команду».
3. Вставь команду в игровую консоль и нажми Enter. Она включает `sv_cheats 1`, выставляет позицию и направление взгляда и выдаёт нужную гранату.
4. Выбери гранату и повтори бросок по карточке. Кнопка «Ссылка на раскид» копирует адрес выбранной карточки.

## Запуск из папки

```powershell
cd "$env:USERPROFILE\Desktop\CS2"
py -m http.server 8765 --bind 127.0.0.1
```

Открой [локальную страницу](http://127.0.0.1:8765/). Сайт состоит из статических файлов и готов к публикации через GitHub Pages из корня ветки.

## Данные

- Шесть записей получены из официальных Map Guides установленной CS2 (Steam build 26798866). Точные координаты игрока и углы взяты из узлов игрового гайда. [Описание Map Guides от Valve](https://www.counter-strike.net/newsentry/532126482488623353)
- Пять записей взяты из открытых гайдов. Прямые ссылки находятся в карточках. Две записи содержат опубликованное время полёта. При сортировке по времени записи без замера идут последними.
- Схема Mirage построена по локальной навигационной сетке. Маркеры используют геопривязку игрового радара. Подпись «зона» означает приблизительный ориентир. Пунктир соединяет старт и цель на плане.
- Координаты новых раскидок можно снять командой `getposcopy_exact` в локальной тренировке. Записи каталога хранятся в [lineups.js](./lineups.js). [Список команд из сборки CS2](https://raw.githubusercontent.com/SteamTracking/GameTracking-CS2/master/DumpSource2/commands.txt)
