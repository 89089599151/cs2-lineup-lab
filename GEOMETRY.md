# Mirage: геометрия и надёжность поиска смоков

## Что получили из `de_mirage.vpk`

В исходном Valve VPK находятся оригинальные ресурсы Mirage. Утилита `tools/extract_mirage_vpk.py` проверяет CRC и извлекает их в `geometry-source/maps/...`:

- `de_mirage.nav` — сетка навигационных областей для игроков (доступные уровни пола).
- `de_mirage.vmap_c` — скомпилированные данные карты.
- `de_mirage/world_physics.vmdl_c` — **скомпилированная физическая модель мира**, а не уже готовый список треугольников.
- `world_physics.vrman_c` и `world.vwrld_c` — дополнительные ресурсы мира.

`tools/extract_mirage_nav.py` декодирует NAV v36: 2 544 трёхмерных полигонов. Файл `assets/mirage-nav.json` содержит их игровые координаты, номера областей и связи. **NAV не включает полную физику гранат: крыши, грани коробок и невидимые коллизии нельзя восстановить только из неё.**

## Что исправлено сейчас

Исходный симуляционный атлас из `assets/mirage-smokes.json.gz` содержит 143 779 вычисленных траекторий (билд 2000948). Раньше он считал точку остановки гранаты достаточным основанием для поиска. Теперь `tools/score_mirage_atlas.py` для каждой конечной точки ищет настоящий навигационный полигон под её XY и интерполирует высоту пола в координатах CS2:

| Код | Число | Значение | В расчётном поиске |
|:---:|---:|---|---|
| 0 | 71 309 | Вне проходимых полигонов. Может быть крыша, коробка, край или нормальный игровой объект | Нет, пока нет проверки физики/игры |
| 1 | 64 939 | По высоте близко к игровому полу (допуск 28 юнитов) | Да, **только симуляционный кандидат** |
| 2 | 7 531 | Совпадение по XY с NAV, но другая высота | Нет |

Классификация записана в `assets/mirage-atlas-quality.bin` (один байт на строку, индексы строго соответствуют исходному атласу). `smoke-search.js` загружает этот файл и не допускает в расчётный поиск строки со статусами 0/2. `geometry-guard.js` блокирует некорректный файл, неподходящую карту и билд атласа. Индексы траекторий в `smoke-paths.gzpack` **остаются неизменными**.

**Ни один из 64 939 кандидатов не следует автоматически называть рабочим смоком.** Они всего лишь проходят проверку высоты пола; NAV не гарантирует отсутствие столкновений по пути или правильное раскрытие дымовой завесы.

Существующий публичный каталог и до изменений отображал только смоки, отдельно подтверждённые броском внутри CS2. Эту защиту сохранили: расчётные траектории не выдаются за проверенные.

## Воспроизведение / повторный расчёт

Из корня проекта:

```bash
python tools/extract_mirage_vpk.py "/path/to/de_mirage.vpk" geometry-source
python tools/extract_mirage_nav.py geometry-source/maps/de_mirage.nav assets/mirage-nav.json
python tools/score_mirage_atlas.py assets/mirage-nav.json assets/mirage-smokes.json.gz assets/mirage-atlas-quality.bin
node --test
```

После обновления CS2 потребуется проверить и при необходимости пересчитать результаты для новой версии карты и физики.

## Что требуется для полной проверки «дым на крыше / недолёт»

1. **Декодировать `world_physics.vmdl_c` в реальную коллизионную сетку** (треугольники, коллизионные hull, поверхности и объекты) через инструменты Source 2, например Source 2 Viewer. Проверить соответствие координат.
2. Построить 3D-BVH/AABB-tree и проверять **каждый отрезок** полёта гранаты на пересечение с геометрией, включая карнизы, стены, крыши и невидимые коллизии. Нельзя проверять только конечную точку.
3. Сопоставить с текущей CS2 динамику гранаты, броски `stand`/`jump`/`step`, скорость игрока, силу броска, положение глаз и release timing. Атлас сейчас покрывает только `stand`/`jump` и ограниченную сетку направлений.
4. Сравнить предсказанную точку раскрытия, время и отскоки с серией **реальных бросков** в игре на данной версии CS2 (эталонные случаи: окно, short, jungle, CT, connector; ближние/дальние броски). При расхождении отказаться от линии либо переобучить модель.
5. Возвращать в пользовательский каталог только записи, проверенные в CS2. Остальные хранить отдельно с честным статусом «симуляция, не подтверждено».

**Статус работы:** VPK и исходная физика мира извлечены; NAV декодирован и применён к конечным точкам. Полная физическая коллизия стен/крыш из `world_physics` ещё **не декодирована и не подключена**, а значит проблемы всех недолётов и крыш пока окончательно **не устранены**.
